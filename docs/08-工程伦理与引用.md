# 八、工程伦理、数据说明与引用

## 1. 数据来源声明

- **真实网络模式**：通过 `https://dummyjson.com/products?limit=12` 获取公共演示 API 的商品列表。DummyJSON 本身提供演示数据，不等于真实商家库存或报价。服务不可达时展示实际错误，不把 Mock 内容替换成真实结果。
- **Mock 模式**：`MockProductGateway.ets` 中的 5 件商品及其价格、库存、描述均是用于测试的本地样例，数据源在界面直接标注为 Mock。
- **离线缓存**：Preferences 存储的是先前成功显示的公开商品快照，不能解释为“实时”商品数据。
- **原型图**：`docs/prototype.html` 是静态交互原型，不是从模拟器截取的运行结果。

## 2. 隐私与安全

Preferences 只存收藏 ID 和公开商品字段，不保存账号密码、访问令牌、Cookies、精确位置或个人信息。对用户展示成功的持久化操作必须等待 `flush()` 完成。公开 HTTPS 请求由 NetworkKit 发起，不内置真实凭证。


## 3. 引用资料

1. 华为开发者联盟，[HarmonyOS Navigation 页面跳转](https://developer.huawei.com/consumer/en/doc/HarmonyOS-Guides/arkts-navigation-jump/)，用于 `Navigation`、`NavPathStack`、路由回传。
2. 华为开发者联盟，[Preferences 数据持久化](https://developer.huawei.com/consumer/en/doc/HarmonyOS-Guides/data-persistence-by-preferences/)，用于 KV 读写与 `flush`。
3. DummyJSON，[Products API 文档](https://dummyjson.com/docs/products)，用于产品列表字段结构。
4. 课程前期实验（实验五）原生 ArkTS 商品 App 的功能与交互作为项目的增量起点；本次按四层结构重新组织，并新增接口契约、Mock/HTTP Gateway 与完整交付文档。

## 4. 运行验证与证据要求

只能使用目标设备真实截图或原始运行日志证明效果。失败的外网请求要记录失败，不可把 Mock 模式画面标成网络成功。团队评审与协作记录必须基于真实分支、PR 与审查活动，不得使用虚构姓名或审批结果。
