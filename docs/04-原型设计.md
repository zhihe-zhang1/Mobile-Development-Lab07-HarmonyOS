# 四、页面原型与交互说明

独立可查看的静态交互原型：[`prototype.html`](prototype.html)。**它只是设计与答辩用的浏览器原型，不是 ArkTS 模拟器运行截图**。

## 1. 商品页

```text
┌────────────────────────────────┐
│ LAB 07 · ARKTS                 │
│ 商品服务台                      │
│ 页面 / 组件 / 状态 / 服务        │
├────────────────────────────────┤
│ 数据源与状态验证                │
│ [真实网络] [Mock 商品]          │
│ [空列表]   [模拟失败]           │
│ Mock 与真实接口明确区分         │
├────────────────────────────────┤
│ 加载成功 · Success  来源说明    │
│ [搜索商品名称/分类/编号______]  │
│ 筛选结果：5 件                  │
│ ┌────────────────────────────┐ │
│ │ 无线蓝牙耳机   ¥129.00   > │ │
│ └────────────────────────────┘ │
│ ...                            │
├────────────────────────────────┤
│          商品   |   收藏        │
└────────────────────────────────┘
```

点击不同数据模式时先展示 Loading，再显示实际结果；Error 显示错误和重试、缓存入口；Empty 显示空列表提示。搜索无结果与接口空数组需区分。

## 2. 商品详情页

```text
┌────────────────────────────────┐
│ < 商品详情                     │
├────────────────────────────────┤
│ 商品名称 / 分类 / 编号          │
│ 价格 / 库存                    │
│ 商品描述                       │
│ 收藏商品（重启保留）      [●]  │
│ [保存收藏并返回]                │
│ [不保存直接返回]                │
└────────────────────────────────┘
```

保存按钮把 `DetailResult` 回传给列表页，由状态层先完成 Preferences 写入，再更新收藏标签；不保存直接返回，不改变收藏。

## 3. 收藏页

共用 `ProductList` 组件，但数据源来自 `CatalogStore.saved()`，由当前商品与公开商品缓存合并筛选；当所有收藏不可见时显示说明。底部 Tab 属于同一页面导航，不压入详情栈。

## 4. 交互与反馈准则

- 所有模式由明确按钮选择，默认使用可离线展示的 Mock。
- “保存成功”必须以 `flush()` 完成作为条件。
- 显示数据来源，避免把 Mock 结果误称真实请求。
- 失败文案同时提供下一步操作，不能只显示空白页面。
