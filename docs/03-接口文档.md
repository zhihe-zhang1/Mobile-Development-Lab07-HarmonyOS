# 三、接口文档：先定义契约，再并行实现

## 1. 本地服务契约

```typescript
export interface ProductGateway {
  list(): Promise<Product[]>;
}

export interface Product {
  id: string;
  name: string;
  category: string;
  price: number;
  currency: string; // CNY | USD
  stock: number;
  description: string;
}
```

`ProductService.list(mode: LoadMode)` 根据 mode 选择 `HttpProductGateway` 或 `MockProductGateway`。**调用方不需知道底层来源**，不同实现必须返回相同结构：成功返回数组，失败抛出异常；空数组不是错误。

| LoadMode | 来源 | 预期结果 |
| --- | --- | --- |
| `Network = 0` | DummyJSON | 返回真实商品数组，异常展示错误 |
| `Sample = 1` | Mock | 等待 900ms，返回 5 件本地商品 |
| `Empty = 2` | Mock | 等待 900ms，返回 `[]` |
| `Failure = 3` | Mock | 等待 900ms，抛出 `模拟请求失败（Mock 测试）` |

## 2. HTTP API

**请求**

```http
GET https://dummyjson.com/products?limit=12
Accept: application/json
```

**第三方文档字段（简化）**

```json
{
  "products": [
    {
      "id": 1,
      "title": "Demo product",
      "category": "beauty",
      "price": 9.99,
      "stock": 42,
      "description": "Example only"
    }
  ],
  "total": 100,
  "skip": 0,
  "limit": 12
}
```

上面的 JSON 是说明字段的示意样例，**不是一次实时请求的抓包记录**。具体数据以实际接口返回为准，部分字段或商品内容可能变化。

**字段映射**：`id → API-{id}`、`title → name`、`category → category`、`price → price`、`stock → stock`、`description → description`、`currency = USD`。Mock 商品标识为 `EL-101` 等，币种 `CNY`。不同来源不可混称同一份真实库存。

**超时和异常**：连接超时 8000ms，读取超时 10000ms；非 2xx、JSON 无法解析、数组缺失或字段不符合约定时抛出异常。网络底层可能返回 DNS、连接、TLS 错误码，服务层显示适当提示并保留可排查信息。

## 3. 导航参数契约

```typescript
class DetailRequest {
  id: string;
  favorite: boolean;
  product: Product;
}
class DetailResult {
  id: string;
  favorite: boolean;
}
```

页面使用 `NavPathStack.pushPathByName('ProductDetail', DetailRequest, onPop)` 进入详情。点击保存时 `pop(DetailResult)`；点击不保存时仅 `pop()`，调用方不会收到收藏更改。参数 ID 必须与商品快照一致。

## 4. 状态契约

| LoadStatus | 页面内容 | 触发原因 |
| --- | --- | --- |
| `Loading` | 进度指示器 | 请求开始 |
| `Success` | 商品卡片 + 搜索 | 返回非空数组 |
| `Empty` | 空数据提示 | 返回空数组 |
| `Failure` | 错误原因 + 重试 | 请求抛出异常 |

错误不应由 Mock 假装成真实网络反馈；测试面板直接标明来源。

## 5. KV 结构

Preferences 文件：`lab07_preferences`。

| Key | Value | 用途 |
| --- | --- | --- |
| `favorite_product_ids` | JSON 字符串（数组） | 商品收藏 ID |
| `last_success_products` | JSON 字符串（商品数组） | 最多 80 件公开商品快照 |

本地数据损坏时对单个字段恢复默认值；调用写入 `put` 后等待 `flush`，确保 UI 成功提示与实际持久化结果一致。

## 6. 兼容性与变更规则

团队先评审本页契约，再分别开发真实服务、Mock、组件与页面；变更字段必须同步更新 Model、契约样例、测试和 README。拒绝在页面内硬编码网络返回结构。
