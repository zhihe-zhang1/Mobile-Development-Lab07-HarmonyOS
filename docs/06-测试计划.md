## 已可在非 DevEco 环境执行的检查

```bash
node tests/contract.test.mjs
```

契约检查覆盖：项目配置、INTERNET 权限、路由映射、四层文件存在、Mock 样例字段及公开数据安全范围。通过只代表这些静态断言成立，不代表 HarmonyOS 编译通过。
