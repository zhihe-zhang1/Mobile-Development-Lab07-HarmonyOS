# 九、打包与交付流程

## 1. 工程源码包

项目根目录保留 `AppScope/`、`entry/`、`hvigor/`、`oh-package.json5`、`build-profile.json5`、文档、契约及测试。**不要把 `node_modules`、`.hvigor`、IDE 缓存、`entry/build`、私钥或本地环境凭证混入 GitHub 提交**。

在 Windows PowerShell 中可运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\package-source.ps1
```

生成 `release/Lab07-source.zip`，可以作为源代码提交包；ZIP 中含完整 DevEco Studio 项目与文档。

## 2. HAP 构建（需要 DevEco Studio）

1. 使用 File → Open 打开本工程根目录。
2. 确认系统 SDK、API 版本与 `entry` 模块同步完成。
3. 选择对应 Build 菜单进行 `entry` HAP 构建（菜单名称可能随 IDE 版本变化）。
4. 根据 IDE 构建输出定位生成的 `.hap`，确认调试签名与目标设备安装条件。
5. 安装/运行后依据 `docs/06-测试计划.md` 执行测试，收集真实截图和日志。
6. 只在 HAP 构建成功并经过安装测试后，才把该 HAP 标为已验证的应用包。

由于当前自动化环境没有 DevEco Studio/HarmonyOS SDK，**不能在此生成或声称存在经过验证的 `.hap` 文件**。本次交付为可导入 IDE 的工程源码和文档。
